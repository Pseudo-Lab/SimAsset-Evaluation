### 📌 작성 가이드

**날짜**
정기적으로 만나는 날짜 또는 해당 주차의 주요 활동일을 적어주세요.

**시간**
모임 시작–종료 시간을 적어주세요.
예: `19:00–21:00`

**주요 활동**
그 주에 팀이 함께 할 핵심 활동을 한 줄로 적어주세요.

**결과물**
그 주가 끝났을 때 남아 있어야 하는 것을 적어주세요.

> **Tip.** 모든 주차를 촘촘하게 계획할 필요는 없습니다.
> 프로젝트의 흐름이 보이도록 **Explore → Build → Test → Share**의 여정을 설계해보세요.

> 일정은 프로젝트에 맞게 자유롭게 수정해주세요.
