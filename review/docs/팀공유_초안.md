# Discord 공유 메시지 초안

검사 결과를 받아 영상·그래프·측정값을 보고 판정과 메모를 남기는 로컬 시제품을 준비했습니다. 주영님 빗면 코드와 민경님 홈 검사 코드를 직접 재현해 연결했고, 자동 검사 67개와 실제 화면을 확인했습니다.

원본은 보존하고 같은 결과의 재전송·ID 충돌·파일 누락을 구분합니다. 홈 검사 대상이 아닌 결과도 실패와 분리하며, 공을 놓기 전 빈 값은 0으로 바꾸지 않습니다. 실행 예정 목록과 비교해 폴더 자체가 빠진 경우도 찾도록 했습니다.

Grafana는 조회, 별도 화면은 판정 입력을 맡는 구성입니다. Nebius L40S에서도 샘플 3종을 비교했고, 같은 Linux VM의 소프트웨어 렌더링보다 영상 저장과 전체 처리가 빨라졌습니다. 실제 50개 처리량이나 최종 청구액까지 확인한 결과는 아닙니다.

이제 실제 검사 결과와 연결하려고 합니다. 검사별 결과 한 묶음과 선정 ID 대응표를 공유받으면 대조하겠습니다. 세욱님·검사환경팀과 ID·규약·반복·수정 규칙을, 회광님·성준님과 화면·판정 기준을 함께 맞추면 좋겠습니다. 팀원 한 분과 가져오기부터 판정 저장까지 재현 확인도 해보고 싶습니다.

공유 시 붙일 자료: 코드·시연 링크, 결과 검증 문서, 제출 규칙 초안입니다. 현재 로컬 주소는 다른 컴퓨터에서 접속할 수 없으므로 공유 가능한 코드 링크 또는 함께 보는 화면이 필요합니다.

---

이 메시지는 초안이며 전송하지 않았습니다. 개인 날짜별 실행계획과 계정·청구 상세는 포함하지 않습니다. 팀의 실제 결과 50개, 나머지 검사 어댑터, 공동 DB 연결, 팀원 재현과 피드백은 확인 대기입니다.
