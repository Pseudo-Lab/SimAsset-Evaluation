# Discord 공유 메시지 초안

검사 결과를 가져와 영상·그래프·측정값을 보고 판정과 메모를 남기는 로컬 시제품을 준비했습니다. 공유된 빗면 검사 코드의 샘플 3종을 직접 실행했고, 중복 입력·ID 충돌·파일 누락·단위 오류와 판정 수정 이력도 확인했습니다.

원본 파일을 보존하고, 자동 실행 상태와 사람 판정을 나누는 방식으로 만들었습니다. Grafana에는 읽기 전용 조회를 연결하고 판정 입력은 별도 화면에서 처리하도록 구성했습니다. 하나의 웹앱으로 통합하는 방식도 비교할 수 있습니다.

현재는 로컬 샘플 재현 결과입니다. 팀의 실제 50개 결과와 다른 검사 출력은 추가 대조가 필요하며, Azure GPU 실험도 아직 실행하지 못했습니다. 우선 실행 ID·규약 버전·반복 번호, 판정 항목과 필수 근거를 어떻게 맞출지 의견을 부탁드립니다.

시연과 재현 문서를 준비했습니다. 공유할 때 접근 가능한 코드·시연 링크를 붙이면 됩니다.

---

위 메시지는 작성 초안이며 아직 보내지 않았습니다. 긴 결과는 `검증결과.md`와 `필드대응과선택.md`를 바탕으로 노션 결과 문서로 옮길 수 있습니다. 날짜별 개인 실행계획은 포함하지 않습니다. 팀 공동 저장소에 올리기 전에는 원본 코드·에셋의 공개 범위와 별도 구현의 검토를 확인합니다.
