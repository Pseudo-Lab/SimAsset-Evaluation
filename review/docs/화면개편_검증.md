# 결과 검토 · Grafana 화면 개편

2026년 11월 18일 기준입니다. 이미지 생성으로 만든 시안을 참고해 결과 검토 웹앱과 Grafana의 정보 순서, 색상, 상태 표현을 맞췄습니다. 기존 원문과 판정 저장 구조는 유지합니다.

## 화면에서 달라진 점

| 화면 | 변경 내용 |
| --- | --- |
| 공통 | 짙은 회색 표면, 민트색 강조, 일관된 테두리·여백·글자 위계를 사용합니다. 자동 실행 상태와 사람 판정을 다른 이름으로 표시합니다. |
| 실행 목록 | 에셋·조건 검색, 판정 없는 실행·오류 빠른 필터, 추가 필터 접기를 제공합니다. 같은 에셋의 반복 실행은 짧은 실행 ID로 구분합니다. |
| 시뮬레이션 검토 | 실제 저장 영상을 중심에 두고 외형·충돌 형상을 전환합니다. 짧은 영상도 길이를 소수 초로 확인하고 0.25배속으로 볼 수 있습니다. 실시간 시뮬레이션 실행 화면은 아닙니다. |
| 측정값 | 세 가지 핵심 측정값과 하나의 선택형 그래프를 먼저 보여줍니다. 전체 측정값, 판정 이력, 검사 조건·파일은 탭으로 전환합니다. |
| 판정 입력 | 넓은 화면에서는 영상 오른쪽, 좁은 화면에서는 아래에 배치합니다. 판정 선택, 미저장 표시, 근거 파일 수를 명확하게 표시합니다. |
| Grafana | 저장된 실행·에셋 이름·실행 오류·판정된 실행을 먼저 보여주고, 상태 분포 → 최근 판정 → 에셋별 표 순으로 구성합니다. 긴 측정값 표는 필요할 때 펼칩니다. 실행 링크는 해당 영상·판정 화면으로 연결됩니다. |

## 데이터 표시 원칙

- 시안의 인명·예시 수치·영상은 구현 데이터에 사용하지 않습니다. 웹앱은 기존 API와 원본 영상만 표시합니다.
- `실행 완료`는 하네스 실행 상태입니다. 사람의 `통과 / 불통과 / 보류`와 구분합니다. `probe_pass`도 사람 판정으로 전환하지 않습니다.
- `대상 아님`은 오류나 불통과로 표시하지 않습니다. 미측정은 0으로 채우지 않습니다.
- 그래프는 빈 관측 구간을 선으로 이어 붙이지 않습니다. 키보드 방향키 또는 포인터로 관측값을 확인할 수 있습니다.
- 핵심 깊이 값은 SI 저장값을 mm로 환산합니다. 전체 측정값 탭에는 SI 값과 원본 값·단위를 함께 보존합니다.
- Grafana의 에셋 수는 **에셋 이름 종류 수**입니다. 여러 버전이나 실행을 50개 실물 에셋 평가 완료율로 해석하지 않습니다.
- Grafana는 기존 조회 전용 DB 계정과 기본 패널만 사용합니다. 외부 플러그인·공유 DB·GPU 자원은 추가하지 않습니다.

## 검증 결과

| 검증 | 확인 결과 |
| --- | --- |
| Python 회귀 검사 | 68개를 통과했습니다. 새 집계 쿼리의 실행 수·에셋 이름 수·판정된 실행 수를 실제 임시 PostgreSQL에서 확인했습니다. |
| 표시 규칙 검사 | Node 검사 4개를 통과했습니다. 조건 조합, 해시 미기록, 빈 시계열, 0과 미측정, SI 환산을 확인했습니다. |
| 실제 데이터 표시 | 로컬 원본 27개 실행, 7개 에셋 이름, 판정이 있는 실행 1개를 유지했습니다. |
| 브라우저 저장·수정 | 별도 시험 DB에서 판정 저장 후 새로고침·이력 불러오기·수정을 수행했습니다. 항목 `cavity`, 기준 `visual-qa-1`, 이유와 근거 파일 2개가 유지됐고 이전 판정도 남았습니다. |
| 영상·그래프 | 실제 영상의 로딩·재생, 0.25배속, 외형/충돌 형상 전환, 그래프 항목 전환을 확인했습니다. |
| 화면 폭 | 내부 브라우저의 1048px·1280px 화면과 390px 좁은 화면에서 확인했습니다. 좁은 화면에서 페이지 전체의 가로 넘침이 없었습니다. 임시 뷰포트 설정은 복원했습니다. |
| Grafana 연결 | 최근 판정의 링크로 `block_mu03`의 해당 실행 ID가 열리는 것을 확인했습니다. 상태 분포는 완료 24, 오류 1, 대상 아님 2로 일치했습니다. |

브라우저 저장 시험은 원본 DB와 분리한 임시 DB에서 진행했습니다. 시험 기록을 팀 평가로 추가하지 않았고, 검증 후 임시 DB·서버·탭을 정리했습니다. 검증 범위는 로컬 검토 앱과 로컬 Grafana이며, 공개 배포나 다른 팀원의 기기 검증은 포함하지 않습니다.

## 라이트 · 다크 테마 추가

검토 화면에 라이트·다크·시스템 선택기를 추가했습니다. 선택을 첫 화면 표시 전에 적용하고 브라우저에 저장합니다. 그래프·배지·입력창·표의 색상과 로고도 함께 바뀝니다. 390px 폭에서는 탐색 링크를 다음 줄로 배치해 테마 선택기가 잘리지 않습니다.

Grafana는 고정된 밝은 색상 대신 테마에 대응하는 기본 색상 이름을 사용합니다. **테마 설정** 링크와 기본 **Change theme** 메뉴를 사용합니다. URL만 바꾸는 같은 화면 내 이동은 테마가 즉시 반영되지 않아 빠른 전환 링크로 채택하지 않았습니다.

- 검토 화면의 라이트·다크 전환, 새로고침 후 선택 유지, 시스템 모드 선택을 확인했습니다. 전환 중 검색값과 선택한 실행이 유지됐습니다.
- Grafana의 기본 메뉴에서 테마 선택과 사용자 설정 저장을 확인했습니다.
- 390px 폭에서 페이지 너비는 375px이었고, 테마 선택기가 화면 안에 표시됐습니다. 임시 화면 크기 설정을 복원했습니다.
- 표시 규칙 검사 4개와 JavaScript 구문 검사를 통과했습니다. Grafana SQL은 이전 버전과 동일합니다.
