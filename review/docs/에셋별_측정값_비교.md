# 에셋별 측정값 비교 대시보드

검사 하나와 지표 하나를 고르면 여러 에셋의 값을 한 화면에서 나란히 봅니다. 영상을 보기 전에 **어느 에셋·실행부터 볼지** 고르는 데 씁니다. 통과·불통과 판정은 이 화면이 아니라 [결과 검토 화면](../README.md)에서 영상을 보고 남깁니다.

| 화면 | 보는 것 |
| --- | --- |
| 검사 결과 현황 (`simasset-local-review`) | 결과가 몇 건 들어왔는지, 오류·판정 상태 |
| **에셋별 측정값 비교** (`simasset-asset-compare`) | 같은 지표에서 어느 에셋·실행이 튀는지 |
| 결과 검토 화면 | 실행 하나의 영상·시계열·측정값, 사람 판정 |

## 여는 곳

Grafana에서 **SimAsset local** 폴더의 **SimAsset · 에셋별 측정값 비교**를 엽니다. 주소는 `/d/simasset-asset-compare`입니다. 팀 서버의 실제 주소와 포트는 [컨테이너 안내](../../.devcontainer/README.md#실행)의 접속 주소 표를 보고, 팀 안에서 공유한 값을 씁니다. 로컬에서는 컨테이너 환경의 Grafana를 실행하면 같은 대시보드가 함께 올라옵니다.

## 화면 구성

맨 위의 **검사**와 **지표**를 고르면 아래 세 패널이 모두 그 지표로 바뀝니다. 지표 목록에는 에셋이나 실행 사이에 값 차이가 있는 지표만 나옵니다.

| 패널 | 내용 | 이렇게 읽습니다 |
| --- | --- | --- |
| 에셋별 대표값 (막대) | 에셋마다 중앙값. 0/1 지표는 1인 실행의 비율 | 혼자 길거나 짧은 막대가 먼저 볼 에셋입니다 |
| 에셋별 분포 (표) | 실행 수, 값 없음, 최솟값·중앙값·평균·최댓값 | 최솟값과 최댓값 차이가 크면 조건이나 seed에 따라 결과가 갈리는 에셋입니다 |
| 전체 중앙값에서 먼 실행 30개 (표) | 모든 에셋의 실행 중 값이 전체 중앙값에서 가장 먼 순서 | **실행 보기**를 누르면 결과 검토 화면에서 그 실행의 영상이 열립니다 |

패널 제목 옆의 `i`에 마우스를 올리면 패널 설명이 나옵니다.

## 사용 순서 예시

1. **검사**에서 `settle`, **지표**에서 `jitter`(떨림)를 고릅니다.
2. 막대에서 `sphere_offcom`만 약 800 mm/s이고 나머지 에셋은 0에 가깝습니다. 이 에셋을 먼저 봐야 합니다.
3. 아래 실행 목록 맨 위 행의 **실행 보기**를 눌러 영상을 확인합니다.
4. 영상에서 문제가 맞는지 보고 결과 검토 화면에서 판정을 남깁니다. 둥근 에셋은 MuJoCo에 구름 저항이 없어 실제보다 오래 흔들릴 수 있습니다([공통규약 6장](../../docs/검사환경-공통규약-전체본_v4.md#6-정지-판정과-지표)).

## 값 읽는 법

DB에는 SI 단위(m, rad)로 저장되어 있지만, 화면에서는 공통규약과 지표 이름이 쓰는 단위로 바꿔 보여 줍니다.

| DB 저장 | 화면 표시 | 예 |
| --- | --- | --- |
| 이름에 `_pct`가 들어간 지표 (0~1) | % | `energy_increase_pct` |
| m | mm (이름이 `_m`으로 끝나면 m 그대로) | `peak_pen`, `slide_mm` / `travel_m` |
| m/s | mm/s | `jitter`, `drift` |
| rad | ° | `tilt_final_deg`, `axis_dev_max_deg` |
| rad/s | rev/s | `omega_rev_s` |
| bool (0/1) | 1인 실행의 비율 | `toppled` 0.5 = 실행 절반이 넘어짐 |
| 단위 없는 수 | 그대로 | `mu_k_eff`, `slip_ratio` |

- **값 없음**은 계산되지 않은 실행 수입니다. 예를 들어 빗면에서 미끄러지지 않아 마찰을 역산하지 못한 경우입니다. 0으로 채우지 않으므로 대표값과 분포 계산에서 빠집니다.
- 지표마다 큰 값이 나쁜지 작은 값이 나쁜지가 다르고, 기준선도 아직 정하지 않았습니다. 그래서 실행 목록은 크기가 아니라 **전체 중앙값과의 거리**로 정렬합니다. 차이 칸이 음수이면 중앙값보다 작은 실행입니다.
- 지표의 정의는 [공통규약 6장](../../docs/검사환경-공통규약-전체본_v4.md#6-정지-판정과-지표)에 있습니다.

## 한계

- 현재 DB 뷰(`review.v_run_metrics`)에는 실행 조건(빗면 방향, 낙하 각도 등)이 없습니다. 그래서 **한 에셋의 모든 조건과 seed를 합쳐** 계산합니다. 조건에 따라 값이 크게 갈리는 spin·incline 지표는 결함이 묻힐 수 있습니다.
- 이 화면은 보조 도구입니다. 막대가 튀지 않는다고 통과로 보지 않습니다.

## 고치거나 확인할 때

- 대시보드 정의: [`grafana/asset-compare.json`](../grafana/asset-compare.json). `review/grafana/`의 JSON은 Grafana가 시작할 때 자동으로 불러옵니다.
- Grafana는 읽기 전용 계정으로 `review.v_run_metrics`만 조회합니다. 다른 테이블을 쓰는 쿼리는 권한 오류가 납니다.
- 쿼리 테스트: `review/`에서 `uv run pytest tests/test_grafana.py`를 실행합니다. 단위 변환, 0/1 비율, 값 없음 집계, 조회 범위를 확인합니다.
