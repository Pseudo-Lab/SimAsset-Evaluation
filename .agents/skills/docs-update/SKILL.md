# 저장소 문서 업데이트

1. [문서 목록](../../../docs/README.md)에서 독자가 시작할 곳과 해당 내용의 기준 문서를 찾습니다. 개발 시작은 [저장소 사용 안내](../../../CONTRIBUTING.md), 로컬 실행은 [결과 검토](../../../review/README.md), 컨테이너 운영은 [운영 안내](../../../.devcontainer/README.md)에 맞춥니다. 규약과 이미 결정된 팀 합의는 해당 원문을 연결합니다.
2. 명령·옵션은 실제 CLI나 스크립트와, 설정은 견본과, 결과 형식은 규약과 구현에 대조합니다. 같은 절차가 여러 군데에 있다면 기준 문서를 고치고 다른 위치에서 연결합니다. 동작을 확인한 버전과 팀에서 논의 중인 내용은 각각 명시합니다.
3. 절차에 필요한 작업 폴더, 입력, 실행 명령, 성공을 확인할 위치를 적습니다. 가능한 경우 작은 샘플이나 전용 로컬 환경으로 따라 해보고, 링크와 경로를 확인합니다. 직접 실행하지 못한 운영 환경이나 플랫폼이 검증 범위에 중요하면 남겨둡니다.
